Downloads

Two ways to run Lark

Same IDE. Different packaging. Executable is the default — unzip and run, which avoids Windows Setup / SmartScreen fights. Desktop Setup is still available if you want Start Menu shortcuts.

Recommended

Lark Executable

Extract All, then double-click Lark.exe. No batch files & No Installer.

  • Windows · zip
  • ~72 MB
  • No .bat required
  • Own update channel
Download lark-executable-windows.zip

Do not run from inside a zip preview or Temp folder.

Optional Setup

Lark Desktop

Windows Setup wizard with Start Menu and desktop shortcuts. Installs under your user folder. Some PCs block unsigned Setup downloads — if SmartScreen fights you, use Executable instead.

  • Windows · Setup.exe
  • ~45 MB download
  • ~200 MB with JDK
Download LarkDesktopSetup.exe

Mac / Linux: mac.zip · linux.zip

1. Extract the zip

Download Lark Executable, then Right-click → Extract All to a real folder (not Temp).

2. Open Lark

Double-click Lark.exe. Optional: Desktop Setup still adds Start Menu shortcuts if you prefer that path.

3. Write Java

Open a project, use live compile feedback, Run with Ctrl+Enter, search with Ctrl+Shift+F.

Ecosystem

Other Lark versions

Executable and Desktop are the PC tracks. Lark Mobile is the phone IDE — Android APK plus a host engine for compile/run.

Lark Mobile

Phone-first IDE with the same Desk themes as Desktop. The Android APK runs Java on the device — write, check, run, and debug with no PC required (Wi‑Fi host pairing stays as fallback).

APK runs on-device · v3.9.7.32

Mac / Linux Desktop payload

Zip payloads with start-lark-desktop.sh and the same buried app/ + jdk/ layout. Windows Setup remains the primary Desktop path.
